# CloudCCB
## Project Overview

CloudCCB is a Cloud-Based Configuration Change Board system designed to manage configuration items, change requests, approvals, and audit tracking.

## Software Configuration Management (SCM)

Git is used for version control, and GitHub hosts the project repository. IntelliJ IDEA provides Git integration for managing branches, commits, and changes.

## SCM Activities

1. **Configuration Identification:** Identify and organize project files and configuration items.
2. **Change Control:** Create a separate Git branch for a proposed change before modifying the main codebase.
3. **Status Accounting:** Track changes through Git commits, branch history, and repository updates.
4. **Configuration Verification:** Review code changes and test the application before merging them.
